# Reflection

## 1. Өнөөдөр юу сурсан бэ?

Өнөөдөр PostgreSQL болон pgAdmin орчинтой танилцаж,
шинэ database болон table үүсгэж сурсан.

Мөн CREATE DATABASE, CREATE TABLE, INSERT INTO,
SELECT зэрэг SQL командуудыг ашиглаж сурсан.

## 2. Ямар алдаа хамгийн сонирхолтой байсан бэ?

INTEGER төрлийн age баганад 'twenty' гэсэн TEXT утга оруулахад
алдаа гарсан нь сонирхолтой байсан.

Энэ алдаанаас column бүр өөрийн data type-тай бөгөөд
оруулах утга нь тухайн төрөлтэй тохирох шаардлагатайг ойлгосон.

## 3. PostgreSQL-ийн юу ойлгомжгүй үлдсэн бэ?

SERIAL төрөл яг хэрхэн автоматаар дараагийн id утгыг үүсгэдэг нь байсан.
