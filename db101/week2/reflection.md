# Reflection

## 1. Client-Server ойлголтоос юу ойлгосон бэ?

pgAdmin нь database биш, харин PostgreSQL server-тэй холбогддог
client програм гэдгийг ойлгосон.

SQL command-ыг pgAdmin-аас илгээдэг боловч database болон data-г
PostgreSQL server хадгалж, command-ыг server талд гүйцэтгэдэг.

## 2. Permission алдаа яагаад чухал вэ?

Permission нь хэрэглэгч бүр ямар үйлдэл хийж болохыг хязгаарлаж,
өгөгдлийн сангийн аюулгүй байдлыг хамгаалдаг.

Хэрэглэгчид шаардлагагүй эрх өгөхгүй байх нь database-ийн
өгөгдлийг санамсаргүй өөрчлөх, устгахаас хамгаална.

## 3. Ямар хэсэг хамгийн ойлгомжгүй байсан бэ?

Database-ийн CONNECT эрх, schema-ийн USAGE эрх болон CREATE эрх
тус тусдаа байдгийг эхэндээ ялгахад бага зэрэг ойлгомжгүй байсан.

Практик дээр permission denied алдаа гаргаж үзсэний дараа эдгээр
эрхүүдийн ялгааг илүү сайн ойлгосон.
